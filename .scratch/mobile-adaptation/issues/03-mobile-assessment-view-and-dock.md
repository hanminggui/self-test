# 03: 答题互动核心屏拆端与触控重构 (Mobile Assessment View & Bottom Dock)

**What to build:**
为受试者提供单手即可流畅完成全流程测验的移动端答题交互界面：将答题界面重构为上部题干内容弹性滚动、底部常驻拇指触控操作栏（包含选项矩阵与下注置信度控制），并通过底部抽屉展示解题提示，消除一切误触与拥挤。

**Blocked by:** 01: 全局移动端基底与通用抽屉容器 (Foundation & Mobile BottomSheet Layout)

**Status:** ready-for-agent

- [ ] 抽离独立的移动端答题视图组件，仅在移动端视口挂载，底层状态机与题目数据保持严格一致。
- [ ] 题干描述与点阵/几何符号矩阵支持自适应缩放与垂直滚动，保证在小屏下高清晰度且无左右截断。
- [ ] 底部固定常驻拇指操作区（Bottom Action Dock）：单选选项采用触控友好的大块卡片，置信度下注控件易于单手点选或滑动。
- [ ] 提示解锁采用滑起式 BottomSheet 抽屉展现，可查看分值消耗并解锁提示，支持下滑收起。
- [ ] 所有交互控件（选项卡片、下注刻度、操作按钮）触控热区均 $\ge 44 \times 44\text{px}$，底部适配安全区边距。
- [ ] 使用 `agent-browser` 模拟完整单题作答流程，验收无横向溢出且交互断言通过。
