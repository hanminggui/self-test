# 04: 测评报告与原生海报分享 (Diagnostic Report & Mobile Share)

**What to build:**
让完成测试的移动端用户能够一目了然地阅读其认知原型诊断报告，并以最符合移动端直觉的方式生成、长按保存高清海报到系统相册，或通过系统原生分享面板将结果一键分享至社交平台。

**Blocked by:** 01: 全局移动端基底与通用抽屉容器 (Foundation & Mobile BottomSheet Layout)

**Status:** ready-for-agent

- [ ] 诊断报告结果页单列垂直流式排布，八维图表、原型称号、优势与成长建议卡片在小屏下自适应缩放无裁切。
- [ ] 海报生成弹窗在移动端自动切换为自适应全屏浮层，生成原生 `<img>` 标签供用户长按直接“保存到手机相册”。
- [ ] 分享操作优先唤起移动设备系统原生 Web Share API（`navigator.share`），非支持环境下平滑降级为一键复制短链。
- [ ] 确保专属分享着陆页（SharePage）在小屏下展示清晰，呼应原型的视觉风格。
- [ ] 使用 `agent-browser` 自动化验收报告渲染与海报图片生成，无横向溢出。
