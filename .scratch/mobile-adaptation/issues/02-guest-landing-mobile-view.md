# 02: 游客落地页移动端体验重构 (Guest Landing Mobile View)

**What to build:**
让移动端访问游客落地页的用户获得流畅自然的首屏感知与滚动浏览体验：首屏星空英雄区自适应当前视口完整展现测试引导与主要行动号召（CTA）按钮，原型轮播与轨迹展示区域在触控下顺滑滚动且无任何横向溢出。

**Blocked by:** 01: 全局移动端基底与通用抽屉容器 (Foundation & Mobile BottomSheet Layout)

**Status:** completed

- [x] 游客落地页在 `390x844` 及 `360x640` 视口下无横向水平滚动条（`scrollWidth <= innerWidth`）。
- [x] 首屏英雄区星空背景与标题、副标题在小屏下自适应比例缩放，确保“开始测试”行动按钮首屏可见且触手可及。
- [x] 原型粘性滚动展示带与轨迹展示组件适配触摸滑动（touch-friendly），滑动动效平滑且不卡顿。
- [x] 核心交互按钮与游客直接开始测验按钮的点击热区达到或超过 44x44px。
- [x] 使用 `agent-browser` 完成移动端视口端到端自动化验收并留存截图。
